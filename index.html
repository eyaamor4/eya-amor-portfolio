Agent LLM pour scanner de vulnérabilités

Securas Technologies · Stage, février – mai 2026

Les rapports de scan se lisent à la main, et beaucoup d’alertes sont de faux positifs. J’ai conçu un agent LLM qui interprète les résultats des scans web et réseau, puis les classe selon CVSS, CWE et OWASP Top 10.

  1. Entrée : Scan web, Scan réseau
  2. Agent LLM : LangChain, OpenAI API, Mistral, Ollama
  3. Classement : CVSS, CWE, OWASP Top 10
  4. Sortie : API REST (FastAPI), Rapport

Taux de faux positifs réduit de 96 %.

Code propriétaire : seul le schéma d’architecture est public.

Projet personnel
